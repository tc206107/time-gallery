# 时光画廊 · 离线目录版使用说明

本目录是「时光画廊」的离线目录版：程序代码已内联进 `index.html`，
画作与缩略图作为独立文件放在 `assets/` 下，总体积约 40 MB。

## 与单文件版的区别

| | 单文件版 | 本目录版 |
| --- | --- | --- |
| 形态 | 1 个 HTML（约 33 MB） | 目录（约 40 MB） |
| 打开方式 | 双击 `index.html` | 需本地静态服务器（见下） |
| 画作画质 | 1280 px 长边 | 1600 px 长边 |

## 为什么本目录版需要静态服务器

`file://` 下浏览器会把本地图片判定为跨源，Three.js 的 WebGL 贴图会抛 `SecurityError`，
展厅里只剩空白画框。因此本目录版**必须**通过 HTTP 打开。任选一种方式：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

然后浏览器访问 `http://127.0.0.1:8000/`。

如果希望「双击即玩、不要服务器」，请使用**单文件版**
（`release/时光画廊-离线单文件版.html`）。

## 操作

**电脑**：点击画面锁定指针，`WASD` / 方向键移动，鼠标旋转视角；
点击画框或按 `E` 看详情，`Esc` 关闭。

**手机 / 平板**：单指拖动旋转视角，轻点画作看详情，左下角摇杆移动。
